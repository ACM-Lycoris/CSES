# CSES Solutions

This repository contains my C++ solutions to the [CSES Problem Set](https://cses.fi/problemset/).

Solutions are grouped by problem set section. Each `.cpp` file is a standalone solution and can be compiled separately.

## Usage

Compile any solution with a C++17 compiler:

```bash
g++ -std=c++17 path/to/solution.cpp -o solution
```

The repository is updated as I work through the problem set. Comments use basic English and explain only the parts that may not be clear from the code.
